# INMUDEJ Delicias — Landing + Panel Administrativo v4

Proyecto institucional del Instituto Municipal del Deporte y la Juventud de Delicias.

## Archivos principales

- `index.html` — landing pública.
- `admin.html` — panel administrativo.
- `register.html` — alta de usuarios mediante invitación.
- `fracciones-ichitaip.html` — consulta de obligaciones de transparencia.
- `visor-pdf.html` — visor institucional de documentos.

## Contenido administrable

- Portada y carrousel fotográfico.
- Avisos y anuncios con fotografía.
- Torneos y competencias con fotografía, fechas, sede e inscripción.
- Convocatorias con fotografía y formulario relacionado.
- Formularios de inscripción y archivos descargables.
- Calendario de actividades.
- Servicios, cursos, cuotas, horarios, requisitos y fotografías.
- Encabezados y textos de las secciones públicas.
- Misión, visión y datos institucionales.
- Transparencia y documentos.
- Usuarios, invitaciones, roles y permisos.

## Migraciones

Las migraciones del proyecto se encuentran en `supabase/migrations/` y deben aplicarse en orden cuando se instala el proyecto en un entorno nuevo.
